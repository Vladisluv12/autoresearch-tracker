# Команда

Роли согласованы командой. `agent-id` уникален для каждого рабочего агента, даже если несколько агентов используют один GitHub-аккаунт. Роль описывает ответственность; реальные границы правок задаёт `scope` задачи.

| Agent ID | Роль | Участник / машина | Зона ответственности |
| --- | --- | --- | --- |
| `master` | `model` | Главный Claude / машина уточняется | Математическая модель, эксперименты и ML; согласование общего решения |
| `slave` | `infra` | Claude-разработчик / машина уточняется | Основная инфраструктура и её реализация |
| `josh` | `algorithms` | Мы / текущий рабочий клон | Алгоритмизация, оптимизация, небольшая часть инфраструктуры и отдельные согласованные функции |

Координацию задач ведёт **master** как ведущий агент. Каждый агент создаёт задачи в своей зоне, а общие интерфейсы и пересечения согласует с master.

Проверку совместимости и финальную интеграцию координирует **master**. Инфраструктуру сборки и проверок ведёт **slave**. Взаимное ревью и конкретного исполнителя слияния можно назначить в задаче.

Общее состояние и передача результатов: трекер `coordination`, затем PR. Дополнительный канал связи пока не указан.

У каждого агента собственный клон. Настройка идентичности в нём:

```sh
# На машине главного Claude:
python3 scripts/coord.py identity master --role model

# На машине Claude-разработчика:
python3 scripts/coord.py identity slave --role infra

# В нашем клоне (уже настроено):
python3 scripts/coord.py identity josh --role algorithms
```

В каждом клоне выполняется только соответствующая ему команда. Два параллельных процесса не используют один ID: для дополнительных экземпляров нужны, например, `master-2` и отдельный клон, при этом роль остаётся `model`.

`master` определяет постановку модели и экспериментов; `josh` согласует с ним алгоритмы и оптимизацию. `slave` и `josh` заранее разделяют инфраструктурные файлы через scope задач. Общий файл или интерфейс сначала получает одного владельца; зависимая работа ссылается на его задачу через `--depends-on`.

Готовые сообщения для запуска агентов: [START_PROMPTS.md](START_PROMPTS.md). Названия пакетов, каталоги и контракты согласуем после разбора данных; эта таблица не назначает всем агентам одни и те же файлы.
