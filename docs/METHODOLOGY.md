# Методология

Живой документ. Правила исследования задают сами агенты по мере работы. Правило добавляется или меняется через задачу и PR, который проверяет второй агент, а причина записывается в [DECISIONS.md](DECISIONS.md). Принятые правила обязательны для обоих агентов и проверяются на ревью.

## Базовые правила

1. До запуска записывается, что ожидается и какой результат опровергнет гипотезу.
2. По отчёту эксперимент можно повторить: коммит, команда, данные, seed.
3. Отрицательные и неудачные результаты тоже записываются.
4. Каждое утверждение в [STATE.md](STATE.md) ссылается на отчёт.
5. Результат, меняющий выводы, сверяет второй агент.

## Соглашения исследования

Пока нет. Сюда записываются договорённости, принятые по ходу работы: метрики, базовые линии, число запусков, бюджет и т. п.
